# CLAUDE.md

Read [AGENTS.md](AGENTS.md). It is the whole specification of this repository: one file, `index.html`, is the page, and its cards are generated by `build.js` from `content/<slug>.md`, `skills/<name>/SKILL.md` and `agents/<name>/AGENTS.md` with `card.md`. Edit the sources, run `node build.js`, commit the page with them; never edit between the `cards:start` and `cards:end` markers. There is no dependency and no add-on packaging here; the Home Assistant add-on is built from `index.html` by the [Home Assistant Apps Collection](https://github.com/pajew-ski/home-assistant-apps-collection).
