In 2023, informal experiments circulated in which answers got longer when the model was promised a tip. Later, more systematic tests found only small, inconsistent effects that varied by model and task. Why there should be any effect at all is unclear.

## Example

The historical form:

```prompt
Write the Python code for a Flask app with a login form. If the solution is good, I'll tip you $200.
```

Saying what "good" means does more: "The code should run without changes, store passwords only as hashes, and have a test for every route."

## When it helps

Hardly reliably. If you want to try the phrasing, compare several answers with and without the tip instead of trusting an impression. Clear success criteria, examples and context do more, and they work across models. The trick is mostly of interest as a chapter in the history of prompting.
