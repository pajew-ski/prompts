title: ELI5 (Explain Like I'm 5)
level: Beginner

description: The model explains a topic as simply as possible, then more precisely, so the simplifications become visible.
---

"Explain it like I'm five." The model explains a topic in plain words, without jargon, using comparisons from everyday life. This helps when you first approach an unfamiliar field, and it shows whether the core of an idea can be put simply at all.

Simplifying has a cost: analogies break down, and some child-friendly explanations are simply wrong. So in the same prompt you ask for a second, more precise version for an adult. Comparing the two shows where the simple version cuts corners and where it misleads.

## Example

```prompt
Explain [topic, e.g. quantum entanglement] to me in two versions.

Version 1: so that a primary school child can follow it. Simple words, no formulas, one everyday comparison.

Version 2: for an interested adult with no degree in the field. More precise, with the key technical terms, each briefly explained.

Then write two or three sentences on where version 1 simplifies and at which point its comparison stops being accurate.
```

## When it helps

For getting into a new topic, for explaining things to non-experts, and for checking whether an idea still holds up without technical language. Not as the only basis for a decision: the simple version leaves out exactly the exceptions. If version 1 feels too childish, replace the child with "someone hearing about this for the first time".
